# CFTR F508del: CRISPR-Cas9 Replication Project

## Project Overview

This project investigates how CRISPR-Cas9 can be used to correct the F508del mutation in the CFTR gene, which is associated with cystic fibrosis.

## Research Question

How effectively can CRISPR-Cas9 correct the F508del mutation in the CFTR gene?

## Original Research

Smirnikhina et al. (2020).

*P.F508del editing in cells from cystic fibrosis patients.*

[PLOS ONE — Original Research Paper](https://doi.org/10.1371/journal.pone.0242094)

## Project Objectives

- Understand the CFTR gene and F508del mutation.
- Investigate the CRISPR-Cas9 editing strategy.
- Reproduce and analyse published experimental results.
- Evaluate the effectiveness and limitations of the approach.

## Method

This is a computational and literature-based replication. It uses published experimental designs and results rather than performing gene editing in a laboratory.

## Author's Reflection

## Author Reflection

This project helped me understand how CRISPR-Cas9 can potentially be used to correct genetic mutations such as CFTR F508del, which is associated with cystic fibrosis.

One of the most interesting parts was comparing different Cas9 and guide RNA combinations and analysing the published results. I learned that the highest reported precise genomic HDR value does not mean that the same percentage of all cells were successfully corrected. Understanding this distinction helped me interpret the data more carefully.

A challenge was understanding the difference between HDR and NHEJ and how the researchers measured editing efficiency. Working through the paper and organising its results helped me develop my scientific reading and data analysis skills.

This was a literature-based computational replication, not a laboratory experiment. It showed me both the potential of gene editing and the challenges that still need to be addressed before it can become a reliable treatment.
